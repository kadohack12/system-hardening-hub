# Sécurisation & Durcissement Windows

Ce répertoire contient les ressources de durcissement et de sécurisation pour les environnements Windows.

## Contenu

- [scripts/](scripts/) : Scripts de configuration et de durcissement (PowerShell, etc.).
- [gpo/](gpo/) : Exportations et configurations des objets de stratégie de groupe (GPO).

## Utilisation

Veuillez vous référer aux guides spécifiques présents dans chaque sous-dossier pour exécuter les scripts ou importer les configurations GPO.
